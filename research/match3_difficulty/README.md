# 三消难度量化实验 A

本包包含 100 局已认证关卡、候选筛选流水、自动玩家结果、补充安全质量审计和复现源码。实验运行在 Ubuntu 26.04 WSL2，处理器为 Ryzen 7 5800X，使用 GCC 16.2 Release 构建。求解器为 `rock2matrix/match3-strict` 的 `71aac8aab2e3fae2fa798e075f0f7d52b1220754`。[实验使用的提交](https://github.com/rock2matrix/match3-strict/tree/71aac8aab2e3fae2fa798e075f0f7d52b1220754)

## 棋盘与证书

所有棋盘都是 8×8、5 色、起始无匹配。累计达到任意颜色消除目标且棋盘稳定后结算。每次合法交换消耗一步。每波补充最多 12 格，颜色尽量均分，余数分给编号较小的颜色。求解限制为 256,000 个候选检查、720,000 个补充枚举节点、6,000 个展开状态、单次交换最多搜索 9 波连锁。

旧附件的固定样本中，认证关卡集中在一步关。为覆盖剩余步数和后继盘面，本实验沿用旧生成算法，使用新种子，分别累积四组各 25 个通过独立回放的证书。四组的目标／总步数为 6／3、10／4、8／2、10／3。每组按种子递增，满额即停止。候选数和认证比例仅代表这次按配额筛选的样本。

## 代理与计分

所有代理都只决定合法交换。交换后由同一份证书指定补充序列。选择动作时，代理使用当前棋盘、目标、步数和各自策略允许的计算。动作价值并列时均匀抽取。

| 代理 | 策略 |
| --- | --- |
| Random | 均匀抽取合法交换。 |
| Greedy | 最大化首波消除数。 |
| Objective | 最大化自然补充下的预期已完成目标量。依次以本回合达标机会、较小的超额消除量打破平局。 |
| Lookahead | 最大化自然补充下的预期价值。价值为本回合总消除，加一半额外连锁波数，加一半下个盘面最佳首波可贡献的剩余目标进度，本回合达标时再加 3。 |

Objective 和 Lookahead 在每个状态、每个动作上采用同一套固定种子的 24 次配额补充探测。探测达到单波结构上限或深度截断时，该次贡献为零。模拟每局每代理 1,000 次，同时沿证书图计算精确概率。精确概率的随机性来自并列动作和 Random 的均匀选择，条件为这份证书和固定探测。动作评估和补充探测次数记录每回合策略所需工作量。程序复用了缓存以减少实验执行时间。

实验在基础目标结算时记录累计消除、余步和连锁。主挑战为累计消除至少达到目标加 3。另算目标加 1、目标加 6、至少余一步，以及至少有一次交换发生两波消除。本次使用累计消除量作为计分代理。真实玩家的决策耗时、星级阈值和能力分层需要实际测试。

## 特征与补充质量

- D1 对每局进行 512 次自然补充的 Random 对局，用目标除以总步数与自然补充每次执行交换平均消除量的乘积。深度或批次限制中断时保留已完成波次的消除量。另记达标、批次越界、深度截断和无合法交换的比例。
- D2 对每个合法首交换各试 256 次自然补充。用完成波次的平均消除量作为动作价值，计算温度为 1 的归一化 softmax 熵和最佳与次佳价值差。
- D3 记录颜色熵、匹配密度、每个探测的连锁波数及影响格子。影响格子包括交换端点和各波次每个被消除格子所在列从该格往上的范围，按本次交换内的并集计数。
- D4 记录各代理的结算表现和挑战达成率。
- D5 每一波在合规颜色配额内均匀抽取排列。已达到目标或后继状态出现在已验证证书图中时，可确定为安全。超出单波补充上限、最后一步结算仍未达成或稳定后无合法交换且尚未达成时，可确定为不安全。其余样本保留为未解析。`root_safe_mass_lower` 与 `root_safe_mass_upper` 对应已知安全及可能安全事件的样本比例。证书所选完整补充轨迹的自然概率另算，其互补概率为该确定性控制器在该交换上的轨迹总变差。单见证轨迹与安全集合的质量含义不同。
- 补充审计使用独立首交换与补充样本。基础分类无法裁定时，以有界预算求解稳定后继，并独立回放新增通关证书。统计见 `results/safe_mass_audit.csv`，审计范围为首步。

## 文件与复现

| 文件 | 内容 |
| --- | --- |
| `dataset/settings.csv` | 四组种子、配置和预算。 |
| `dataset/candidates.csv` | 全部候选的判定、展开计数、验证及耗时。 |
| `dataset/boards/`、`dataset/certificates/` | 100 个入选棋盘及其证书。其它候选可凭种子重新生成。 |
| `results/levels.csv`、`results/root_actions.csv` | 每关特征和首交换级自然样本统计。 |
| `results/policies.csv` | 400 项关卡 × 代理汇总及精确概率。 |
| `results/board-policy-intervals.csv` | 每关每代理的模拟达成率、精确率和 Wilson 区间。 |
| `results/difficulty-summary.json` | 分层统计、代理对照和特征相关。 |
| `results/human_pilot_shortlist.csv` | 真人测试候选，按分层和代理结果覆盖不同关卡。 |

在 WSL 解包后，使用已克隆、对应提交的求解器和一个新的运行目录。`run.sh` 会重建、运行 CTest、生成所有候选、回放证书并重新输出各表。重跑的计时会随机器负载变化。

```bash
bash run.sh ./solver-checkout ./reproduced
```
