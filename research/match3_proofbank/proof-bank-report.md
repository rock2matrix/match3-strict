# ACR v1.1 Proof-Bank Expansion 验收

**定向扩库已完成，继续使用固定见证和冻结的 V1 生产分档。** 扩库提高了对自然补充的认证覆盖，ACR 回退从 7.02% 降到 5.90%。相对同库固定 6 次，ACR 节省的决策 CPU 为冷况 4.37%、热况 3.86%。回退和 CPU 两项均未达到原验收门槛。

## 扩库方法

用原 ACR 走 200 个认证棋盘的独立离线回放，每局、每代理 24 次。记录实际访问的精确棋盘、剩余目标和步数、交换、首波补格及列空位、证明来源和查表结果。把未决且已稳定的活跃后继按完整状态去重，再按出现次数降序补证。每局最多 240 次额外离线求解，已有同预算未决的重复项单列。

只有完整 Strict 续局和自然交换轨迹均验证通过，才能写入新库。新增库离线冻结。线上仍按原动态 K 公式、最多 6 次自然提案和预算约束运行，未找到已证安全提案时回退见证。Base 保留 v1.0 的原预测，扩库版本用独立审计更新 `Z_cert`。固定 6 次在两库使用同一 K，用于检查扩库本身的效果。

实际额外求解 **9,126 次**，新增 **8,628 份**已证安全续局，386 次证实失败、112 次未决。补证使用约 13.05 线程 CPU 秒，另有画像和审计支出。所有棋盘的额外调用均低于每局上限，最多为 227 次。

## 同一提案的覆盖率

7,730 个精确状态与交换组合，每个使用相同的 12 个独立自然提案对照两库。

| 在 92,760 条配对提案中 | 原库 | 扩充库 |
| --- | ---: | ---: |
| 已证安全 | 67,059 | 71,222 |
| 已证不安全 | 4,958 | 4,958 |
| 未决 | 20,743 | 16,580 |
| 已证安全概率质量估计 | 72.29% | **76.78%** |

**4,163 条由未决变为已证安全**，其余状态判定一致。合并抽样提升 4.49 个百分点，棋盘等权提升 3.45 个百分点，配方内配对 95% 区间为 3.21–3.71 个百分点。提升主要来自 10 格／4 步 `multi_slack`，该桶 24,000 条提案中有 2,883 条转为安全，桶内安全比例从 50.57% 到 62.58%。该统计估计的是已证支持集质量 `Z_cert`。

## 新随机流回放与验收

200 个起始棋盘、四种代理、每组合 64 次。两种证明库各比较 ACR 与固定 6 次，关闭 memo 和控制器独享 memo 分开，共 **409,600 局**，全部达到 Strict 基础目标。用于回放的 RNG 与生成候选和估计覆盖率独立。两个缓存条件的非计时行为记录一致。

| 计划验收 | 实测 | 结论 |
| --- | --- | --- |
| Strict 基础目标 100%，未认证执行 0 | 409,600／409,600，未认证执行 0 | 通过 |
| ACR 回退 ≤5% | 7.02% → **5.90%**，同库固定 6 次为 **3.79%** | 未通过 |
| 相对同库固定 6 次 CPU 节省 ≥10% | 冷况 **4.37%** `[3.44%, 5.30%]`，热况 **3.86%** `[3.02%, 4.69%]` | 未通过 |
| 决策线程 CPU P95 ≤2 ms | 冷况 **18.83 µs**，热况 **20.03 µs** | 通过 |
| 首波位置颜色 TV 在预设测量容差内 | ACR **0.01060**，固定 6 次 **0.01022**，差约 0.00039，小于 0.01 容差 | 通过容差检查 |

在线 ACR 提案未决率从 **31.63%** 降到 **27.13%**。固定 6 次的回退也从原库的 5.17% 降到扩充库的 3.79%。CPU 区间按棋盘配对，在四种配方内重采样。CPU P99 冷、热况分别为 27.02、27.88 µs。颜色指标以同库固定 6 次的首波尺寸构成加权，对 3、4、5 格按填充位置计算；它只覆盖该投影分布。CPU 与负载结果对应 WSL 内进程的决策路径。

## 证书版本与难度绑定

200 局的扩充增量已封装为独立可校验档案。**8,628 条新增完整轨迹及续局证书全部独立回放通过**。从 186 个有新增的棋盘各提取最大的一份证书，用 CLI 复验通过；故意改错目标的反例被拒绝。封存清单绑定每个原始棋盘和证书、构建源码、规则与新增档案的 SHA-256。

证明库增量版本 `b2393462faf8f1a8a095836d09e9cfa6d36360bc23443d20e4a946099691b6f8`。

扩库版难度研究模型在原 100 局上锁定切点 **0.690104、0.744792**，在独立于主试验及校准的另一批 200 局上得到困难 **72**、普通 **51**、简单 **77**，四种配方均覆盖三档。与此前 ACR v1.0 的实验档位相比有 76 局不同，该比较包含不同 RNG 样本的估计波动。模型绑定扩充库和控制器版本。原 V1、原生产证书和已入池 120 局按原版本使用。

## 资料和复跑

`results/analysis` 包含逐状态桶、分布、工作量、CPU 和验收指标。`results/bank-audit` 包含独立回放及哈希清单。`results/targeted-warm/bank-entries` 保存全量新增证明和实际补充轨迹，可与原始证书一起审计。正式运行库仍需在服务中实现版本加载、发布和恢复；真实并发和真人难度属于产品验证。

从解压后的根目录执行以下命令。加 `--smoke` 可先验证构建、四组小样本与封存链路。

```bash
git clone ./solver/match3-strict.bundle ./solver-checkout
bash match3_proofbank/reproduce.sh ./solver-checkout ./proof-bank-replay
```
